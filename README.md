- **Contributions** use GitHub's contribution-calendar total for the displayed 365 UTC dates. Today is partial. Commits and pull requests are breakdowns, not additional contributions to add to the total.
- **Visibility** follows the credentials used for the refresh and GitHub's contribution rules. Private activity and different date windows can make a signed-in profile differ from this card.
- **Repositories** are public, owned, and non-fork; archived repositories are included. Stars are recorded in the source data across the same set.
- **Language shares** measure repository source-code bytes, not proficiency, authorship, or time spent coding.
- **Freshness:** scheduled jobs can be delayed, and GitHub can take up to 24 hours to credit contributions. If a job fails or cannot start, the previous snapshot and its original timestamp remain. The workflow badge above links to refresh status.
